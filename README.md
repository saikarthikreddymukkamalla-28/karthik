# TechScroll AI

A hackathon-ready React + TypeScript + Vite demo that turns passive short-form scrolling into adaptive technical learning.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

## Core demo

1. Open **Reel Feed**.
2. Scroll through the seeded fictional tech Reels.
3. Watch/like/save/skip content.
4. Open **Dashboard** to see the interest and skill profile change.
5. Open **AI Recommendations** to see the next-best Reel ranking.
6. Use **Live Demo** to replay the Java Trap + Hype Guard story for judges.

The profile is persisted in localStorage and no external API key is required.
